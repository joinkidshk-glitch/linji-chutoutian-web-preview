## 2. 公式天花板（唔改權重嘅理據）

base = 0.40×主軌（fame/45 或 credit/60，上限 1）＋ 0.42×worksScore（wsum/1.6，上限 1）
＋ tagBonus（MVP 類別冇 tagBonusAny，永遠 0）＋ repPower（跨桶 ≥2 部且最佳 q ≥0.5 → 0.08×crossQ）。
認真玩嘅玩家主軌好快封頂（0.40），所以 base 實際範圍由作品分＋跨桶分決定；
**無 tag 嘅理論天花板係 0.40＋0.42＋0.08 = 0.90**。擔正級玩家（[1.00, 0.78, 0.55] 桶＋跨桶）
base 0.882，已經貼近天花板；再深嘅桶（Y3 E1 深桶 [1.00, 0.78, 0.78, 0.55]）都係 0.882
（worksScore 封頂）。所以單純改權重（例如作品分除數 1.6→2.0）只會成體下移，唔會拉開
頂部差距——贏線先係正確嘅槓桿，權重唔郁。

贏率公式（引擎真實）：score = base + U(−0.05, +0.05)，score ≥ L 先贏；
P(win) = clamp((base + 0.05 − L) / 0.10, 0, 1)。
