## 2. 週／章節結構（一期內容船）

### 2.1 建議（待用戶確認長度）

| 項 | 建議值 | 理由 |

### 2.2 文案「粒度」：每週 vs 每季 vs 每年

| 粒度 | 須準備之文案類型 | Phase1 數量級（規格，非正文） |
|---|---|---|
| **每週** | 手帳週結摘要殼、週末壓力事件（§5）、可選一條「本週何生／NPC 催更」 | 模板為主；週結四至六變體；壓力見 §5 |

## 3. 通告文案庫規格

### 3.1 Schema（凍結＝現有 `gigs_1988`）

每則必填：`id, year, season(春|夏|秋|冬), type(廣告|綜藝|電視劇|電影|唱片通告), title, loc, roleHint, blurb(≤40字), synopsis, heroAngle, diasporaHook, eraTag[], discoverNote, req{acting,stage,looks,stamina,iq,charm,fame,popularity,stress}, pay[min,max], fame[min,max], popularity[min,max], stressDeltaHint(低|中|高), hard(0.2–0.7), tier(初|中|高), shootDaysHint, shootHint`  
`loc` 只允許十一個 `locId`（worldview.companies）。

### 3.2 年配額（不變）

每年：**廣告 8｜綜藝 5｜電視劇 7｜電影 6｜唱片通告 4＝30**  
1988 現況：類型已滿額；tier 約 初11／中12／高7；季節 春7／夏9／秋6／冬8。

### 3.3 難度／tier 閘（文案側指引）

| tier | 玩家階段感覺 | req／hard 文案注意 |
|---|---|---|
| 初 | 開局六至八週主糧 | req 低；blurb 鼓勵「新人可試」；hard ~0.2–0.4 |
| 中 | 首殺青後 | 須一至二項能力明顯高於開局；hard ~0.4–0.55 |
| 高 | 人氣／聲望有基數 | 明確「難搶」；hard ~0.55–0.7；忌開局可硬闖語氣 |

### 3.4 字數與欄位語氣

| 欄位 | 字數指引 | 語氣（見 §3.5 已批） |
|---|---|---|
| title | 短、好記 | 書面語 |
| blurb | **≤40 字** | 書面語＋港味行業詞 |
| roleHint | 一句 | 書面語 |
| synopsis | 二至四句 | 書面語；須有世界觀／衝突／企劃，不可空泛 |
| heroAngle | 一句 | 咬合「草根、隱忍、肯捱」 |
| diasporaHook | 一句 | 兩岸／海外共感 |
| discoverNote | 一句 | 如何於地圖發掘 |
| shootHint | 一句 | 拍攝氣氛 |

## 4. NPC 對話樹規格

### 4.1 雙軌現實（必須講明）

| 軌 | 來源 | 人數 | 現況 | Phase1 策略 |
|---|---|---|---|---|
| **Playable core** | `index.html` `NPCS` | 6 | 各約三句**粵語** random；`homes[]`；`tipGig` 類型偏好 | **加深此六人**；對話池**改寫為書面語** |

**建議（待批）：** Phase1 只加深 HTML-6；Phase2 以 `legacyId`／別名表將可玩 NPC merge／alias 入 `cast_main`（或反向：HTML id → cast id），避免兩套人設永久分叉。

### 4.2 Phase1 優先序

1. **何生**（agent）— 教學、週評、壓力勸退  
2. **Vera**（stylist）— 廣告／唱片形象、造型門檻  
3. **林曉晴**（colleague）— 同期情報、台廠生態  
4. **張子駿**（director）— 電影路線、「演技才是本錢」  
5. **高俊傑**（rival）、**周采兒**（reporter）— 張力／曝光（次優先，同樣須達最低池）

### 4.3 觸發（對齊現機制＋預留）

| 觸發 | 條件 | 抽取 bucket |
|---|---|---|
| 地圖傾談 | 玩家於 NPC `homes` loc 選「傾談」 | greet → chat／advice／intel 權重隨機 |
| tipGig | 好感／機率成功 | 情報句可附於傾談結果（機制已有） |
| 壓力勸 | 週末 stress 高或試鏡前 ≥70 | 優先何生 pressure／advice |
| 好感門檻 | 例：reporter ≥40 小訪 | 專用一句「見報」結果（事件模板） |
| 章節 beat | B07–B10 | 可強制一次「劇本向」對白（仍短） |

### 4.4 每次傾談用量（建議凍結）

- 每次傾談：**只顯示一句**（由池 random），另加 tip／好感／敵對副作用敘事。  
- Bucket 建議擴成（兼容 cast_main 四鍵＋玩法 intel）：

| bucket | 用途 | Phase1 每 NPC 池量 |
|---|---|---|
| greet | 見面 | **6** |
| chat | 閒聊／世界觀 | **8** |
| advice | 成長建議 | **6** |
| intel | 通告／地點暗示（書面語；勿過度寫死 gig title） | **6** |
| pressure | 嘲諷／催更／壓力 | **4** |
| **合計／人** | | **≈30 句** |

六人 Phase1：**≈180 句**（規格目標；生成屬 Prompt B）。  
現有每人約三句粵語底稿＝改寫起點，**擴池不刪機制**；產出必須為書面語。

### 4.5 語氣

- HTML-6：**書面語短句**（由現有粵語三句風格改寫；單句自足）。  
- cast_main：暫保持其 `speechStyle`；Phase2 再統一是否入板，並評估是否一併改為書面語。  
- 禁忌：不用真人藝名；對手／記者衝突保持「輕戲劇」，不升級人身攻擊。

### 4.6 何時擴 cast_main 入玩法

- Phase1 GATE：六人池達標＋主線 B01–B10 對白殼齊。  
- Phase2：選三至四個 cast（例：導師／台柱型）做「條件遇見」——對齊 `meetCondition`，homes 映射至十一個 locId。

## 7. DeepSeek prompt 規格（只殼｜不跑）

共用硬規則（四殼皆須帶）：

1. 繁體；**輸出主幹一律書面語**（可含港產行業詞；禁止粵語口語文法作骨架）（§3.5 已批）。  
2. 遵守 worldview.taboos；locId／屬性 key 白名單。  
3. 輸出 **純 JSON**（不以 markdown 包裝）。  
4. 不發明新 schema 欄位；不改數值公式。  
5. 批量宜細，方便 QA。
