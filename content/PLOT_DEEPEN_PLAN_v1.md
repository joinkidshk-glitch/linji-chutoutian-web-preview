# 《臨記出頭天》劇情加深計劃 v1（草稿｜待用戶拍板）

> **狀態：** 計劃 only — **未產** detail／DeepSeek。  
> **對象：** 用戶 + 星途志願 tester／manager  
> **觸發：** 用戶要求加強劇情深度（預覽 v17m；Phase1 書面語已接入）。  
> **硬約束：** 全面書面語、現代玩家易讀、少文言；標題維持 **「先做到有穩定收入」**；**1988 通告庫不 bulk 重寫**（只 QA）；不發明衝突 schema；機制欄位對齊現有 HTML（好感 0／10／25／40、週結、試鏡／殺青、tipGig）。  
> **閘門：** 用戶批本計劃 → 再開 detail 規格／DeepSeek → wire＋預覽覆測。

---

## 0. 一句總方針

**在既有 Phase1 骨架（教學／六人對話池／W1–12 事件模板／B01–B10／四章）上，加「有代價的選擇」與「記得住的關鍵事件」——主線弧、六人關係、每週至少一則有重量事件、試鏡失敗／殺青／情報與劇情掛鉤；文案加深，玩法數值公式原則不動。**

現況診斷（簡）：

| 層 | 現況 | 深度缺口 |
|---|---|---|
| 主線 B01–B10 | 短對白／章開關 | 動機衝突弱；失敗無敘事代價；幾乎無分叉 |
| 六人 NPC | random 池＋好感解鎖 bucket | 缺「關鍵事件」；關係弧只靠重複傾談 |
| W1–12 事件 | 結算模板（AUD／SHOOT／WEEK…） | 數值敘事多，劇情重量少 |
| 試鏡／殺青／情報 | 結果句＋tipGig | 與 flags／後續節拍少連動 |
| 通告庫 | 30 則已齊 | **本輪不重寫** |

## 1. 主線弧加深（開局 → 穩定收入 → 出頭半步）

### 1.1 三幕情緒（仍鎖在 W1–12／四章）

| 幕 | 週／章 | 玩家應感覺到的張力 | 加深手段（規格級） |
|---|---|---|---|
| **I 站不穩** | W1–3 · Ch1 | 屋租／細佬學費 vs 想正式出道；何生放手但不兜底 | 開場加「家用壓力」一句錨；B01–B03 插入一次「先賺錢還是先練」選擇 |
| **II 有單但不安** | W4–8 · Ch2–Ch3 | 首試鏡成敗都會留疤；殺青入帳 vs 壓力／人情債 | B05／B06 綁 flags；失敗有後續對白，非只換下一張板 |
| **III 半步出頭** | W9–12 · Ch3–Ch4 | 對手／記者／形象路線拉扯；B10 穩定收入判定有敘事重量 | B08–B10 讀 flags；達標／未達各有「代價句」與下季鉤子（仍 Phase1 內） |

### 1.2 動機衝突（建議凍結三條，文案反覆咬合）

1. **家用 vs 劇本理想**（屋邨／租金／寄錢）— 催「穩定有薪」  
2. **何生標準 vs 自己搶通告** — 催「別亂接爛單」  
3. **曝光快（記者／廣告）vs 演技本錢（張子駿）** — 催路線分叉  

### 1.3 失敗代價（敘事，非改公式）

| 觸發 | 敘事代價（建議） | 落地 |
|---|---|---|
| 首次試鏡失敗 | 何生壓力句＋阿偉手帳一句；可設 `flags.firstAudFail` | 擴 `AUD_FAIL` 變體＋B05 後續 |
| 連續失敗（可選 ≥2） | 林曉晴／高俊傑各一句不同語氣 | flag 計數；事件池加條件句 |
| 高壓殺青（stress 高） | wrap 後何生勸休，非純入帳喜悅 | `SHOOT_WRAP` 條件變體 |
| 週末病倒 | 已有 WEEK_STRESS90；加深「錯過一張板」敘事鉤 | 模板加一條劇情向變體 |

### 1.4 選擇分叉（輕量：2～3 個二元選擇，非視覺小說大樹）

| ID | 約週 | 選擇 | 寫入 flag | 後續影響（文案／輕數值） |
|---|---|---|---|---|
| C1 | W2–3 | **先報訓練** vs **先街頭／兼職賺生活費** | `path_train`／`path_cash` | Ch2 開場語氣不同；何生 advice 權重 |
| C2 | W5–7 | 殺青後 **請場務喝茶留聯絡** vs **趕下一張板** | `path_network`／`path_hustle` | B07 人脈三角觸發優先序；情報品質敘事 |
| C3 | W8–10 | 面對高俊傑嘲諷：**當面頂回去** vs **忍下記薄本** | `path_clash`／`path_endure` | B08 結局句；對手 pressure／好感微差（沿用現機制幅度） |

> **不做：** 多結局大樹、戀愛攻略分支重寫、改試鏡成功率公式。

### 1.5 B01–B10 升級方式

- **保留** beat id／週窗；每 beat 由「3 短句」升為 **節拍卡**：`setup`（1）＋`beat`（2～3）＋可選 `choice`（C1–C3）＋`aftermath`（1，讀 flag）。  
- 章開關由氣氛句改為 **衝突句**（仍 ≤3 句）。  
- B10 維持現有達標判定邏輯（fame／money）；文案加強「半步出頭」情緒，**標題／教學 WELCOME 不改短**。

## 2. 六人 NPC 關係線加深

> 範圍：**只加深 HTML-6**（何生／Vera／林曉晴／張子駿／高俊傑／周采兒）。  
> `cast_main` 12 人仍為擴充軌，本輪不強制入玩法。  
> 好感門檻 **維持** 0／10／25／40（寒暄／閒談／忠告／情報對白）。

### 2.1 每人一條「關鍵事件」（Keystone）

| NPC | 關係弧（文案目標） | 建議觸發 | Keystone 事件（一句） | 玩家可見結果 |
|---|---|---|---|---|
| **何生** | 放手→考核→認可半步 | 好感≥25 或 W6／壓力高 | 「要不要拒一張條件差但快錢的通告」 | flag；後續 pressure／B10 語氣 |
| **Vera** | 形象審判→願意管造型 | 好感≥25＋曾接廣告／唱片向 | 「形象一致」檢查：造型／言行打架則勸改 | 忠告池加條件；輕 looks／charm 敘事 |
| **林曉晴** | 同期互助→情報可信 | 好感≥40 或 C2=`path_network` | 傳一則「可靠但要你親自跑」的情報 | tipGig 敘事加強（仍不改通告庫正文） |
| **張子駿** | 嚴→「演技才是本錢」 | 好感≥25＋至少 1 次殺青 | 問你：要曝光還是要層次 | 影響 C 類路線對白；intel 偏電影／演技 |
| **高俊傑** | 嘲諷→真競爭 | W8–9 或好感／敵對閾 | 搶板或當眾調侃（現有 rival 事件升級） | 讀 C3；聲望微懲可沿用 |
| **周采兒** | 取材→小訪見報 | 好感≥40（機制已有） | 小訪題目二選一：談日常 vs 談野心 | 見報句變體；fame 微差敘事 |

### 2.2 對話池策略

- **不重做** 全量 180 句（上輪已現代書面語）。  
- **新增** 每 NPC：`keystone` 專用 2～4 句＋門檻解鎖時 1 句「關係推進」提示。  
- random 池可加少量「讀 flag」條件句（可選，detail 再定上限，避免爆炸）。

## 3. W1–12：每週至少 1 個有重量事件

### 3.1 定義「有重量」

必須滿足至少兩項：**(a)** 推進主線或 NPC 關係；**(b)** 有情緒或代價；**(c)** 可寫入 flag／影響後續一句。  
純數值結算（+錢／−壓）**不算**本條達標。

### 3.2 建議每週 Keystone 表（規格；正文待 detail）

| 週 | Keystone 主題 | 主要出口 |
|---|---|---|
| W1 | 何生放手＋家用錨 | B01＋手帳 |
| W2 | 通告板鎖區挫折／C1 選擇 | B02＋C1 |
| W3 | 首次訓練或兼職後果 | B03＋C1 aftermath |
| W4 | 社交課解鎖／人情開始 | B04 |
| W5 | 第一次試鏡（成敗分支） | B05＋AUD_* |
| W6 | 拍攝中段疲勞或場務人情 | SHOOT_DAY 劇情變體 |
| W7 | 第一單殺青＋C2 | B06＋C2 |
| W8 | 人脈三角之一落地 | B07 |
| W9 | 對手壓力＋C3 | B08＋C3 |
| W10 | 記者眼／小訪前置 | B09 |
| W11 | 穩定收入倒數（差什麼） | 週結劇情句 |
| W12 | 春夏小結 B10 | 達標／未達 |

> 與現有週末壓力事件**並存**：壓力模板保留；Keystone 優先在「週中節拍／傾談／試鏡／殺青」出口播，避免一週末三張卡疊爆（detail 定互斥規則）。

## 5. 範圍／優先序／外置 JSON／不做清單

### 5.1 範圍（本輪）

**做：** 主線節拍加深、輕分叉 C1–C3、六人 keystone、W1–12 每週重量事件規格與文案、AUD／WRAP／情報掛鉤、外置 JSON＋index 內嵌同步。  
**不做：** `gigs_1988` bulk 重寫；cast_main 入板；教學七步大改；UI／畫風；改試鏡公式；Phase2（1989+）。

### 5.2 優先序（建議）

| 序 | 包 | 內容 | 依賴 |
|---|---|---|---|
| **P0** | 主線骨架 | 章開關衝突化＋B05／B06／B10 成敗敘事＋C1 | 僅 beats／events |
| **P1** | 每週重量 | W1–12 keystone 表文案＋互斥規則 | P0 flags |
| **P2** | 六人 keystone | 六場關鍵事件＋少量條件句 | 好感門檻沿用 |
| **P3** | 掛鉤拋光 | AUD／WRAP／tipGig／記者小訪變體 | P0–P2 |
| **P4** | Wire＋QA | 外置 JSON、index 內嵌、tester／iOS 預覽覆測 | — |

### 5.3 外置 JSON（建議：**要**）

| 檔 | 用途 |
|---|---|
| `story_beats_phase1.json` | **擴充**（節拍卡／章衝突句／B10）；維持可 fetch |
| `story_choices_phase1.json`（新） | C1–C3：選項、flag、aftermath 句 |
| `weekly_keystones_phase1.json`（新） | W1–12 每週重量事件 |
| `npc_keystones_phase1.json`（新） | 六人關鍵事件＋條件句 |
| `events_zh_HK.json` | **擴** AUD／WRAP／見報等條件變體（不刪舊鍵） |
| `npc_lines_core.json` | 原則不重產；只補 keystone 相關短句 |
| `gigs_1988.json` | **不動 bulk** |

Wire：與現況一致——`content/*.json` ＋ `index.html` 內嵌快照；`refreshCopyPacksFromDisk` 可顺延支援新檔（detail 定）。

### 5.4 DeepSeek 用法（批準後）

- Prompt **S**：節拍卡／章衝突／C1–C3 正文（書面語短句）。  
- Prompt **W**：W1–12 keystone。  
- Prompt **K**：六人 keystone。  
- Prompt **E+**：事件條件變體增量。  
- **不**開通告庫 Prompt A bulk。

## 6. 成功標準（驗收）

1. 玩過 W1–12：能說出 **至少 3 個**記得住的劇情時刻（非純＋錢）。  
2. 試鏡失敗與首殺青各有 **後續句子**（不是一次性 toast）。  
3. 六人各至少 **1** 場 keystone；好感門檻仍為 0／10／25／40。  
4. C1–C3 選擇會改變 **至少一處**後期對白。  
5. 文風：現代書面語；無文言格言回潮；標題仍為「先做到有穩定收入」。  
6. 通告庫無 bulk diff；tester／iOS 預覽覆測可跑。
