## 2. 建議 JSON schema（增量；唔破舊客戶）

```json
{
  "workTitle": "風燦情迷",
  "genreLabel": "愛情文藝片",
  "director": "王瑞恩",
  "castWindow": {
    "startHint": "1988-03-01",
    "endHint": "1988-06-15",
    "weeks": 15
  },
  "roles": [
    {
      "id": "lead_m",
      "label": "男主角",
      "playerSlot": true,
      "roleHint": "……",
      "req": { "acting": 40, "charm": 30 },
      "pay": [8000, 12000]
    }
  ]
}
```

| 欄 | 必填 | 說明 |
|---|---|---|
| `workTitle` | 建議 | 作品名；與通告 `title`（可含角色／場次）分開 |
| `genreLabel` | 建議 | 細類型標籤；與粗 `type` 並存 |
| `director` | 建議 | 虛構；禁真人藝名 |
| `castWindow` | 可選 | ISO 日或只 `weeks`；缺則 UI 派生 |
| `roles[]` | 可選 | 多角色；`playerSlot:true` 為玩家可報。缺則視整張 gig 為單角色 |

**保留既有：** `id type title loc season tier req pay synopsis roleHint roleScale shootDaysHint shootWeekdays shootDeadlineDays hard fame…`

## 3. 派生規則（無新欄時 UI 仍可出招募單）

### 3.1 作品名
1. `workTitle` 若有 → 用。  
2. 否則 `title` 匹配 `《(.+?)》` → 取內文。  
3. 否則整段 `title`（並在 UI 標「通告題」而非硬叫作品名亦可）。

### 3.2 類型 pill
1. `genreLabel` 若有 → 用。  
2. 否則 map：`電影`／`電視劇`／`廣告`／`唱片通告`／`綜藝`（可再加 `roleScale` 潤：如 `mtv`→「音樂錄像」）。

### 3.3 招募狀態
| 狀態 | 標籤文案 |
|---|---|
| 可報／可搏 | **招募中** |
| 條件未合硬閘 | 仍顯示 **招募中**，條件區顯示未合（唔寫硬鎖） |
| 已約／拍攝中 | **製作中** |
| 已殺青 | **已殺青** |
| 逾期取消 | **已取消** |
| 過季下架 | **已截止** |

### 3.4 通告期間（派生文案例）
- 有 `castWindow`：`{start} ～ {end}，共 {weeks} 週`  
- 無：`{year}年{season}季檔 · 獲聘後 {shootDeadlineDays} 日內完成 · 約 {shootDaysHint} 個工作天`

### 3.5 每週／總天
- **每週：** `shootWeekdays` 去重後個數 → `每週 {n} 天`（另小字可列「逢週一至五」）  
- **總天：** `共 {shootDaysHint} 天`（唱片：`共 {n} 個錄音日`——完整勿截）

### 3.6 難易度 ★（建議）
| 條件 | ★ |
|---|---|
| tier 初 且 hard&lt;0.45 | ★★☆☆☆（2） |
| tier 初 | ★★★☆☆（3） |
| tier 中 | ★★★★☆（4） |
| tier 高 或 film_lead_big／tv_lead_long | ★★★★★（5） |

（精確表可調；UI 只顯示星，唔顯示 `hard` 小數。）

### 3.7 條件列顯示（禁 debug）
跟 `PLAN_GIG_CARD_PLAYER_COPY_v1`：
- 已達：`演技：合組製要求`  
- 未達：`演技：未合組製要求`  
- **唔顯示** `>515`／`差 N`／`你 X`（若要保留門檻數字做「組製標示」，用 `演技　組製要求較高` 或不顯示數字——**預設不顯示原始閾值**；若用戶後日要 MV 式 `> N`，另開閘）。

> 參考圖有 `演技 > 515`。本遊戲數值尺度不同；**v1 建議用合／未合**，避免假大數誤導。若產品堅持 MV 數字牆，用內部 req 值原樣顯示 `演技　> {v}`（仍禁「你 X」「差 N」）。

**拍板預設（劇本建議）：** 合／未合，不顯示閾值數字。iOS 做開關 `SHOW_REQ_THRESHOLD=false`。

### 3.8 片酬
- `酬勞　$ {low} – {high}`  
- 簽約／特殊：MVP `—`（預留兩行對齊參考圖）

### 3.9 劇情簡介
- 正文：`synopsis`  
- 可選上排小節 **角色：** `roleHint`  
- 禁 raw locId；brand 用顯示名（天星音樂等）

## 5. 文案用語（書面＋接通告）

| 位置 | 用 | 不用 |
|---|---|---|
| 狀態 | 招募中、已截止、已殺青、製作中 | 硬鎖、鎖定中、有板 |
| 行動 | 約試鏡、報名、查看通告 | 睇板、跑板 |
| 條件總述 | 條件未合、暫未能報、可搏一搏 | 差 N、你 X、唔能試 |
| 檔期 | 通告期間、每週 N 天、共 M 天、錄音約 M 日 | 限期 20 日（無「獲聘後」時勿裸寫） |

導演／作品名：全面虛構；禁真人。
