## 2. 手動拼合

**玩家流程**
1. **選卡**：喺手帳或情報板點選兩張傳聞碎料卡。
2. **長按或拖近**：長按其中一張拖向另一張，或者同時長按兩張。當兩卡邊緣靠近時，邊緣會泛起微光（UI 視覺反饋）。
3. **確認拼合**：放開手指，彈出「拼合確認」對話框，點擊「確認」完成合併。

**UI 文案與狀態**
- **空狀態**（無傳聞碎料）：「本仔靜雞雞，去金龍茶餐廳飲杯茶聽下風啦。」
- **無可拼合**（兩張卡拉埋但唔匹配）：「呢兩單嘢牛頭唔搭馬嘴，夾硬嚟都冇用。」
- **拼合失敗**（條件不足／中斷）：「諗到一半斷咗思路，遲啲再算。」
- **成功蓋章句**（合併完成）：「啪！蓋個印，呢單嘢有頭緒喇。」

## 6. iOS／Web 接入備註

- **只 Mock 唔改閘**：本階段所有文案與 UI 反饋僅作 Mock 展示，唔改動底層行為閘邏輯。
- **nextHint 隱藏**：iOS 端嘅 `nextHint` 提示喺 Phase 2 Soft 階段必須隱藏，避免提前洩漏 Phase 3 流程。
- **手帳暗紋實作**：Web 端使用 CSS `opacity` 同 `mix-blend-mode` 實現暗紋效果；iOS 端使用 `UIImageView` 調整 `alpha` 值，確保唔影響手帳主體文字閱讀。
- **拖拽拼合手勢**：iOS 使用 `UIPanGestureRecognizer`，Web 使用 Pointer Events，確保長按同拖拽手勢流暢，唔好誤觸。
