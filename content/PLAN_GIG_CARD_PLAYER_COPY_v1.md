## 0. 原則（一句）

玩家睇通告卡，要覺得自己喺**睇真通告／組製回覆**，唔係睇 debug console。

| 要 | 不要 |
|---|---|
| 業界書面語：組製、檔期、試鏡、獲聘、殺青、條件未合 | `差12`、`你25`、`≥30`、`聲望差N`、`條件未夠（演技差5）` |
| 一句講清「點解而家報唔到／可唔可以搏」 | 列數值差額、括號對照現值 |
| 檔期完整可讀（拍攝／錄音日數＋可拍星期＋限期） | 截斷「錄音日」、擠成難讀碎片 |
| Synopsis 一次睇完或自然捲 | **「展開」鈕**（用戶：刪） |

數值可以留喺**內部**算閘／成功率；**玩家面字串唔顯示差額同「你 X」**。

## 2. 鎖因／門檻口吻（取代 `gateShortReason`／`gateTrainHint`／`reqHtml` 玩家面）

### 2.1 硬鎖（唔能試）

**優先只出一句總述**；需要點出缺邊時，用**能力名列表**，**唔帶數字**：

| 情境 | 建議字串 |
|---|---|
| 僅聲望未夠（tier 地板） | `組製暫未考慮你的檔——聲望未合這檔要求。` |
| 僅能力未夠（1–2 項） | `試鏡條件未合：{能力1}、{能力2}。可先安排訓練再報。` |
| 能力未夠 ≥3 項 | `試鏡條件未合：{能力1}、{能力2}等。可先安排訓練再報。`（最多點名 2 項＋「等」） |
| 聲望＋能力同時未夠 | `組製檔與試鏡條件都未合——聲望與{能力1}等尚需再練。` |
| 兜底 | `這張通告暫時未能報名。` |

**板面短標**（卡頭一行，替代 `🔒 聲望差12、演技差5`）：

- 硬鎖：`暫未能報 · 條件未合`
- 可選副行：用上表一句（唔好再拼 `差N`）

### 2.2 軟搏（門檻未齊但仍可試；成功率內部算）

| 位置 | 建議字串 |
|---|---|
| 卡頭 | `可搏一搏 · 條件未齊` |
| 副行（可選） | `組製仍收試鏡，把握視臨場表現。` |
| **唔寫** | `預估成功率 32%` 旁邊再加「（門檻未齊仍可試）」長 debug——若保留 %，只留一句：`可搏 · 成算視臨場` **或** 保留單個 `%` 但刪「門檻未齊仍可試」括註 |

用戶要「接通告感」：軟搏用**口語業界**「搏一搏」，唔好「成功率反映差距」教學句（板頭 lead 一併改，見 §5）。

### 2.3 已消耗／逾期（已有方向，統一書面）

| 情境 | 建議 |
|---|---|
| 已殺青 | `本單已殺青。` |
| 逾期掉單 | `限期內未完成拍攝，組製已取消你的檔期。` |
| 通告唔存在 | `通告已下架。` |

### 2.4 訓練提示（`gateTrainHint`）

| 舊 | 新 |
|---|---|
| `能力門檻未夠（演技差5、體力差3）——去手帳排訓練提升` | `試鏡條件未合。可到手帳安排訓練，再回來報名。` |
| `能力未夠試鏡——睇板得，先去報名訓練` | `暫時未能試鏡。可先報名訓練，再來接這檔。` |

### 2.5 需求列（`reqHtml`——若卡內仍顯示門檻細項）

**禁止：** `演技≥30（你25）`

**改：**

| 狀態 | 字串 |
|---|---|
| 已達 | `演技：合組製要求` |
| 未達 | `演技：未合組製要求` |
| 聲望地板已達 | `聲望：合這檔檔次` |
| 聲望未達 | `聲望：未合這檔檔次` |

若 UI 太長：硬鎖卡**可唔顯示**細項，只留 §2.1 一句。

## 3. 檔期／拍攝・錄音列（meta 一行）

對齊 `PLAN_SHOOT_CAREER_SCHEDULE_v2`；玩家面**完整、唔截字**。

### 3.1 詞彙

| type 族 | 日數說法 | 星期說法 |
|---|---|---|
| 電影／電視劇／綜藝／廣告／寫真 | **拍攝約 N 日** | **逢週{一、二…}拍攝** |
| 唱片通告（錄音／合唱） | **錄音約 N 日** | **逢週{…}錄音** |
| MTV | **拍攝約 N 日**（MV 外景／棚） | **逢週{…}拍攝** |

限期統一：

- 卡面短：`獲聘後 N 日內完成`
- 手帳 HUD（可稍詳）：`拍攝限期：獲聘後 N 日內；可拍：週{…}；尚欠 M 日。`  
  （錄音單：`錄音限期`／`可錄`／`尚欠`）

### 3.2 卡面 meta 拼法（建議順序）

`酬勞約 $ A–B · 拍攝約 N 日 · 逢週一至五拍攝 · 獲聘後 D 日內完成`

唱片例：

`酬勞約 $ A–B · 錄音約 12 日 · 逢週一至六錄音 · 獲聘後 20 日內完成`

**禁：** 把「錄音約 N 日」裁成「錄音日」；禁把限期寫成裸 `限期 20 日` 唔知從邊日起（改「獲聘後」）。

### 3.3 星期標籤

沿用「逢週一、三、五」；若七日全開可寫 `每日可拍`／`每日可錄`（唔寫 `1,2,3…`）。

## 4. Synopsis／「展開」

| 規則 | 說明 |
|---|---|
| **刪「展開」「收起」鈕** | 用戶明確；synopsis **預設全文可見**（或卡內自然捲動，唔要二次點開） |
| 長度 | 現有 synopsis 可保留；若過長用卡內 scroll，唔用摺疊鈕 |
| 文案 | 繼續禁 raw `locId`；brand 用顯示名（天星音樂等） |

## 5. 通告板 lead／鎖卡副行（板頭）

| 舊味 | 新 |
|---|---|
| `免費睇板 · 🔒未達門檻（硬鎖，唔能試）` | `免費睇板 · 有通告暫未能報（條件未合）` |
| `門檻未齊亦可搏（成功率反映差距）` | `免費睇板 · 有通告可搏一搏（條件未齊）` |
| 鎖卡 `未達門檻 · 硬鎖唔能試` | `暫未能報 · 條件未合` |
| 軟 `門檻未齊 · 可搏 · 成功率見上` | `可搏一搏 · 條件未齊` |

約試鏡說明可保留人話：`約試鏡日＝先預約；未獲聘則不開拍。`

1. 鎖卡：無「差 N」「你 X」「≥」；見「條件未合／暫未能報」業界句。

3. 唱片通告：完整「錄音約 N 日」，無截斷。  
4. 卡上**無「展開」**；synopsis 直接可讀。
