# Prompt 4｜通告庫（劇情簡介＋書面語＋華人共鳴）

每年改 YEAR＝1988／1989／1990／1991／1992（可跑 5 次，或一次寫 120 條）。

## 固定規則
- 地點 id 只能用：`tvb_longmen` `tvb_kowloon` `tvb_harbour` `film_lion` `film_cotton` `film_harbour` `rec_hk` `rec_wanchai` `rec_star` `ad_central` `ad_adm`
- 屬性 key：`acting` `stage` `looks` `stamina` `iq` `charm` `fame` `popularity` `stress`
- 史實只作氣氛；劇名／品牌／人名全部虛構；禁止真人姓名、真實商標
- **文案語言：繁體書面語**（可偶爾用港味詞如「屋邨」「通告」「殺青」，但句子用書面語結構；禁止純粵口語如「唔好」「嚟」「咗」「啲」作主體文法）
- **受眾：全球華人**（港、台、陸、東南亞／北美華人）——劇情要寫出跨地域共感（家庭、階層、夢想、面子、離合、打拼），避免只有本地人先明嘅冷梗

## 貼去 Gemini 嘅正文

```
為手遊「臨記出頭天」撰寫 YEAR 年通告 30 則（廣告8、綜藝5、電視劇7、電影6、唱片通告4）。歷史僅作時代氣氛，劇名／品牌／人名一律虛構。輸出純 JSON 陣列。

【文案規則｜必遵】
1. 全部玩家可見文字使用「繁體書面語」：通順、有畫面、可被港／台／陸／海外華人共同閱讀。可保留少量港產行業詞（通告、殺青、龍套、院線），但禁止以粵語口語文法寫整段（勿用：唔、嚟、咗、嘅作主要連接、啲、咁、喺……作為句子骨架）。
2. 面向全球華人玩家：劇情鉤子強調可共感主題——草根逆襲、家庭期待、名利與真心、移民與留下、工廠／屋邨／中環落差、螢光幕前後落差。避免只有香港本地才懂的冷梗或未解釋的地名梗；必要地名可保留但劇情要自足。
3. 每則必須有吸引人的劇情／企劃簡介（synopsis），不可空泛。

每則必填欄位：
id（如 gig_1988_ad_01）, year, season（春|夏|秋|冬）,
type（廣告|綜藝|電視劇|電影|唱片通告）,
title（虛構劇名／廣告案名／節目名，書面語、好記）,
loc（僅限11個指定 locId）,
roleHint（玩家試鏡角色一句，書面語）,
blurb（通告板鉤子，≤40字書面語，令人想點開）,
synopsis（2–4句書面語，必寫且具體）：
  - 電視劇／電影：世界觀＋主角處境＋核心衝突，使玩家想演這個角色
  - 廣告：虛構品牌＋故事板情節（勿寫真實商標）
  - 綜藝：環節設定＋主角出場方式
  - 唱片通告：歌曲／MV 概念或宣傳企劃
heroAngle（一句：此通告如何咬合男主角「草根、隱忍、肯捱」的特質）,
diasporaHook（一句：為何海外／兩岸華人玩家也會想接——家庭、懷舊、夢想等共感）,
eraTag[]（該年氣氛標籤 2–4 個）,
discoverNote（如何在地圖上發掘到此通告，書面語）,
req{屬性key:數字}, pay[min,max], fame[min,max], popularity[min,max],
stressDeltaHint（低|中|高）, hard(0.2-0.7), tier（初|中|高）,
shootDaysHint（整數）, shootHint（拍攝期間氣氛一句，書面語）

要求：同年 30 則 synopsis 不可撞梗；禁止真人姓名與真實商標；文案讀起來像「想追看的劇／想演的角色」，而非作業說明。
```
