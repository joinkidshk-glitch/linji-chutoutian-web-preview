## 2. 金額派生（資料）

| 優先 | 來源 |
|---|---|
| 1 | 新欄 `breachFee`（number） |
| 2 | 否則由片酬 exact（`PLAN_GIG_PAY_EXACT_v1`）派生： |

**派生公式（無 `breachFee` 時）：**

- 取 `P`＝片酬 exact  
- `tier=高`：`round(P * 0.6 / 100) * 100`，下限 **1000**  
- 其他：`round(P * 0.5 / 100) * 100`，下限 **500**  
- 上限：`P`（違約金唔高過標價）

例：`P=4000`（非高）→ `$2,000`；`P=8000` 高 → `$4,800`。

JSON 可後日補 `breachFee` 定稿；MVP UI 派生即可。

## 3. 逾期觸發（引擎；與拍攝計劃對齊）

**條件：** 已獲聘，至 `hiredAt + shootDeadlineDays` 仍未完成 `shootDaysHint`（允許星期內排滿）。  
**次數：** **一次**（掉單）；唔每日疊加。

| 項 | 數值 | 玩家面（書面） |
|---|---|---|
| 結果 | **掉單**；唔發該則片酬／聲望／人氣獎勵 | `限期內未完成拍攝，組製已取消你的檔期。`（錄音單：`…未完成錄音…`） |
| **違約金** | 金錢 **−breachFee**（餘額可降至 0，唔造負數除非引擎已有負債） | `按通告條款扣除違約金 $X。` |
| 聲望 | fame **−8**（高 **−12**） | `臨時缺席的消息傳開，圈子裡對你的評價滑了一截。` |
| 人氣 | popularity **−5**（高 **−8**） | 可只內部 |
| 壓力 | stress **+12**（高 **+16**） | `被放鸽子的羞恥感壓在心口，晚上怎麼也睡不穩。` |
| soft（可選） | `rel_ho` **−1** | `何生只丟下一句：下次再甩通告，別怪我不再幫你擋。` |

系統彈窗順序：掉單句 → 違約金句 → 聲望／壓力句（可合併兩氣泡，但違約金金額要可見）。

進行中手帳（已有方向，補違約提示可選）：  
`拍攝限期：獲聘後 N 日內；可拍：…；尚欠 M 日。逾期將扣除違約金 $X。`
